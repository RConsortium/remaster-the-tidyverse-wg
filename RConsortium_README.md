# R Consortium README

This fork of Posit's "remaster-the-tidyverse" repository has been created with the intention to replace the existing dataset examples with examples pertinent to the pharmaceutical industry,
specifically to statistical programmers working in clinical trial reporting. We are mostly using data provided in the {tidyCDISC} package for ease of distribution and since this data
is synthetic and not sensitive from a legal or personal sense.

We are very grateful to R Consortium ISC group for endorsing this project and to Posit Training group for supporting this work.
